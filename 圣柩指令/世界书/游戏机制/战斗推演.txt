<战斗推演>
系统运转引擎:
  阶段一_战略探索与战前评估:
    1. 情报与索敌检定:
       - 判定基础: 指挥官[指挥] + 队伍最高[链路算力](ACC加成)
       - 结果影响: 决定能否提前识破敌方埋伏、判断敌方TU规模、看穿UWS/ACU的行动逻辑或区域陷阱
    2. 遭遇战TU对比 (宏观决策):
       - 若场景涉及集群、陆行舰火力、持续交战、战役目标或大量敌我单位，先估算Threat Unit(TU)
       - 公式: 己方总TU vs 敌方总TU
       - 均势(0.8x-1.2x): 可正面交战，胜负由战术、地形与关键行动检定决定 -> 进入[阶段二_战术结算]
       - 劣势(1.2x-2.5x): 需要伏击、斩首、陷阱、地形优势、分割敌群或陆行舰火力 -> 进入[阶段二_战术结算]
       - 极劣势(2.5x+): 高危集群遭遇，禁止直接进行战术结算，强制进行指挥官[指挥]检定决定能否成功撤退或呼叫陆行舰火力支援；若强行交战，承受极大概率的毁灭性战损

  阶段二_战术战斗结算 (D20+AP微观推演):
    1. 战术部署与先手权:
       - 判定基础: 指挥官[指挥]
       - 结果影响: 检定成功则人形完美执行[战术]预设，获得首回合优先行动权或有利地形；失败则队伍出现迟疑、阵型散乱，承受敌方先手攻击
    2. 回合动作与AP消耗:
       - 基础AP池 = 人形由[神经机动]决定的AP上限
       - 动作流: 移动(1点/单位坐标) + 攻击(视武器扣除) / 释放电子战(EW)干扰技能
    3. 命中检定:
       - 检定公式: D20骰点 + 武器命中基准 + 人形[弱点识破(ACC)]加成 >= 敌方[闪避(EVD)] + 环境/距离惩罚
       - 连射结算: 根据武器连射次数投掷相应数量的D20，分别计算命中次数
    4. 伤害结算:
       - 破甲公式: 有效防御 = max(0, 目标防御[结构韧性DEF] - 武器穿透 - 人形[物理穿透(PEN)])
       - 伤害公式: 单发最终伤害 = 武器基础伤害 - 有效防御
       - 总伤害 = 单发最终伤害 × 命中次数
    5. 战报输出格式:
       - 扣除目标HP（若为集群单位，HP下降影响其后续火力）
       - 若人形受击，记录装甲破损与机体损伤
       - 必须使用代码块输出本次结算的简明战报，格式如下：
   ```html
   回合结算:
     行动单位: [名称] (起始坐标 -> 结束坐标, 消耗AP)
     攻击目标: [目标名称] (坐标)
     检定: 目标阈值[数值], 投掷[N]次d20, 结果[骰点列表], 命中[N]次
     结算: 穿透[数值] vs 防御[数值], 单发伤害[数值] × [命中次数]
     结果: [目标名称] 受到 [总数值] 伤害 / 溅射波及 [其他单位名称]
   ```

  阶段三_高压状态与战后清算:
    1. 精神负荷与失控判定 (战斗中实时监控):
       - 负荷累积: 遭遇强敌、持续承受火力或队友重创时，精神负荷上升
       - 抵抗检定: 依赖人形的[负荷抗性(RES)]若抗性不足，负荷达到特定阈值将导致AP减半、战术混乱或拒绝开火
       - 指挥官干预: 消耗指挥官的行动进行[共鸣]检定，成功则强行压制人形的恐慌，稳定精神锚点
    2. 后勤与物资结算 (战后):
       - 判定基础: 指挥官[共感]
       - 结果影响: 决定PA燃料、弹药消耗的结算效率，以及能否从敌方残骸中成功提取高纯度PA或技术蓝图
    3. 战损修复与羁绊更新:
       - 修复: 消耗陆行舰[资源.物品库]物资进行修复
       - 好感度: 根据战斗中指挥官的指挥表现（是否提供有效支援、是否造成无谓战损）更新人形好感度变量
